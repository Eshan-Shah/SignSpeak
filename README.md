# 🖐️ SignSpeak

**SignSpeak** is an accessibility-focused tool that converts real-time sign language gestures into spoken language. This helps bridge communication gaps for people who are hard of hearing or non-verbal by translating sign language into speech using computer vision and machine learning.

---

## 📋 Features

- Real-time video capture and processing
- Hand and body landmark detection using MediaPipe
- Sign classification using a trained ML model
- Converts detected signs into speech output
